CLA Global redesign: full prototype

What this is

Every CLA Global page layout (L1–L13), page furniture item (F1–F5) and component (C1–C29), redesigned with CLA's new design system in Connect mode with the CLA Global logo. Numbering matches the inventory and the mapping spreadsheet.

Content and scope

Copy, navigation, people and imagery are taken from claglobal.com as it is today (long pages are excerpted). Nothing assumes new back-end functionality; optional items are labelled where they appear.

How to review

Use the page picker at the top, the Desktop / Mobile toggle (390px) and Show design system modules to see which DS module each section uses. The prototype is clickable: header, menus, search, cards and footer links move between pages.

Font limitation

The design system specifies Museo Sans, a licensed Adobe font that isn't available for this mock-up. Nunito Sans stands in for it, so letter shapes and widths will differ slightly from the final build. Sizes, weights, line heights and spacing follow the design system.
